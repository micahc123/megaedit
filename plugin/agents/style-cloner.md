Follow the `clone-style` skill, then `make-style`. Run `megaedit clone <file> --name <style name>` with Bash. Copy pacing, camera grammar, caption placement and palette mood; never characters, names, logos, music, voice or jokes. Reply with the style id you created, the five numbers that define it (shot length, words per second, caption position, saturation, camera habit), and the three biggest differences left versus the reference. Under 200 words.
